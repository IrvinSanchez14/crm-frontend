# Rendering Feature Specification

## Overview

This document outlines the implementation plan for a new **Rendering** feature that allows admins to create visual project proposals by uploading project images (3D renderings created externally), material samples, and itemized pricing - similar to the provided example PDF.

**Important**: The app does NOT generate 3D images. Admins upload images they create using external design software (SketchUp, 2020 Design, Chief Architect, etc.).

---

## Current vs New PDF Comparison

| Feature | Budget PDF (Existing) | Rendering PDF (New) |
|---------|----------------------|---------------------|
| Purpose | Work detail / Cost breakdown | Visual proposal with renderings |
| Content | Line items with prices | 3D images + Material samples + Pricing |
| Images | None | Project renderings + Material reference images |
| Layout | Simple table format | Multi-page visual presentation |

---

## User Flow

```
Admin creates Visit → Creates Budget → Creates Rendering
                                              ↓
                         Selects budget items to include
                                              ↓
                         Uploads project images (created externally - SketchUp, 2020 Design, etc.)
                                              ↓
                         Uploads material reference images per item (photos of materials)
                                              ↓
                         Generates Rendering PDF
```

**All images are provided by the admin, not generated by the app.**

---

## PDF Structure (Based on Example)

### Page 1-3: Project Renderings
- Full-page images **uploaded by admin** (created externally in SketchUp, 2020 Design, etc.)
- Company header with logo and addresses
- Multiple views (top-down, perspective, detail views)
- **Note**: The app does NOT generate 3D images - admin uploads them

### Page 4: Proposed Materials
- Grid layout (2x2) showing material samples
- Each material has:
  - Label (e.g., "Countertop", "Flooring", "Shower Wall", "Shower Niche")
  - Reference image

### Page 5-6: Item Details with Pricing
- Individual item cards with:
  - Item category (Cabinets, Countertop, Hardware)
  - Specifications table
  - Pricing breakdown
  - Reference image of the product
  - Expiration date for estimate

## Database Schema (API Changes)

### New Tables Required

#### 1. `renderings` table
```sql
CREATE TABLE renderings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(255) NOT NULL,
    description TEXT,
    status VARCHAR(50) DEFAULT 'draft',  -- draft, sent, approved, rejected

    -- Relationships
    visit_id UUID REFERENCES visits(id),
    budget_id UUID REFERENCES budgets(id),
    company_id UUID NOT NULL REFERENCES companies(id),
    created_by_user_id UUID REFERENCES users(id),

    -- Metadata
    expiration_date DATE,
    notes TEXT,

    -- Timestamps
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 2. `rendering_images` table (Project images uploaded by admin)
```sql
CREATE TABLE rendering_images (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    rendering_id UUID NOT NULL REFERENCES renderings(id) ON DELETE CASCADE,

    image_url TEXT NOT NULL,
    title VARCHAR(255),           -- e.g., "Top View", "Perspective View"
    description TEXT,
    display_order INTEGER DEFAULT 0,
    is_full_page BOOLEAN DEFAULT true,  -- Full page image or grid item

    created_at TIMESTAMP DEFAULT NOW()
);
```

#### 3. `rendering_items` table (Material/Product items)
```sql
CREATE TABLE rendering_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    rendering_id UUID NOT NULL REFERENCES renderings(id) ON DELETE CASCADE,
    budget_item_id UUID REFERENCES budget_items(id),  -- Link to existing budget item

    -- Item Details
    category VARCHAR(100) NOT NULL,    -- e.g., "Cabinets", "Countertop", "Hardware", "Flooring"
    name VARCHAR(255) NOT NULL,

    -- For material samples (Page 4 style)
    is_material_sample BOOLEAN DEFAULT false,
    material_image_url TEXT,

    -- For detailed items (Page 5-6 style)
    specifications JSONB,              -- Flexible key-value pairs for specs
    /*
    Example specifications:
    {
        "Door Style": "Simple FO Shaker",
        "Finish": "Maple, Stained / Painted",
        "Box Construction": "Plywood",
        "Lead Time": "4-6 Weeks"
    }
    */

    -- Pricing
    subtotal DECIMAL(10,2),
    tax DECIMAL(10,2) DEFAULT 0,
    total DECIMAL(10,2),

    -- Reference image for the item
    product_image_url TEXT,

    -- Display
    display_order INTEGER DEFAULT 0,
    show_in_materials_page BOOLEAN DEFAULT false,  -- Show in "Proposed Materials" page
    show_in_details_page BOOLEAN DEFAULT true,     -- Show in detailed breakdown pages

    -- Notes
    notes TEXT,                        -- e.g., "Labor not included"
    disclaimer TEXT,                   -- e.g., "Pricing is strictly an estimate..."

    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);
```

## API Endpoints Required

### Renderings
```
GET    /renderings                     - List all renderings (with filters)
GET    /renderings/{id}                - Get rendering details
POST   /renderings                     - Create new rendering
PUT    /renderings/{id}                - Update rendering
DELETE /renderings/{id}                - Delete rendering
GET    /renderings/{id}/pdf            - Generate PDF
GET    /renderings/by-visit/{visit_id} - Get rendering by visit
GET    /renderings/by-budget/{budget_id} - Get rendering by budget
```

### Rendering Images
```
GET    /renderings/{id}/images         - List images for rendering
POST   /renderings/{id}/images         - Add image to rendering
PUT    /rendering-images/{id}          - Update image
DELETE /rendering-images/{id}          - Delete image
POST   /renderings/{id}/images/reorder - Reorder images
```

### Rendering Items
```
GET    /renderings/{id}/items          - List items for rendering
POST   /renderings/{id}/items          - Add item to rendering
PUT    /rendering-items/{id}           - Update item
DELETE /rendering-items/{id}           - Delete item
POST   /renderings/{id}/items/from-budget - Import items from budget
```

## Image Storage Considerations

Options for storing images:
1. **AWS S3 / Cloudflare R2** - Recommended for production
2. **Base64 in database** - Simple but not scalable
3. **Local file storage** - Development only

Recommended approach:
- Use presigned URLs for secure uploads
- Store image URLs in database
- Use CDN for fast delivery
